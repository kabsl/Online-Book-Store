# Online Book Store Management System

A web-based application designed to automate and streamline bookstore operations, inventory management, and customer book ordering. Developed as part of the **IGNOU BCA (BCSP-064)** project curriculum.

---

## 📌 Project Overview
The **Online Book Store Management System** bridges the gap between store administrators, sellers, and readers. It provides a centralized repository for book catalogs, genre-based browsing, automated stock tracking, and user management.

### Key Objectives:
- Provide an interactive, centralized platform for book browsing and purchases.
- Simplify member/customer management and administrative tasks.
- Maintain accurate inventory tracking with automated stock updates.
- Enable feedback collection and rating mechanisms for readers.

---

## 🚀 Key Features

### 👤 User / Member Side:
- **Registration & Authentication:** Secure registration and login handling.
- **Browse & Search:** Categorized exploration of books (Fiction, Non-fiction, Academic, etc.).
- **Order Management:** Add books to cart and place orders.
- **Feedback & Rating:** Submit reviews and ratings for books and service.

### 🛠️ Admin / Staff Side:
- **Catalog & Inventory Control:** Add, update, view, and delete book records (Barcode, Author, Price, Stock).
- **User Management:** Manage customer/member profiles and access privileges.
- **Order Tracking:** Monitor order fulfillment and transaction statuses.
- **Feedback Dashboard:** Review feedback submissions and track issue resolution.

---

## 💻 Tech Stack & Requirements

### Software Specifications:
- **Backend / Core Logic:** Java (JSP, Servlets)
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL
- **Web Server:** Apache Tomcat
- **OS Compatibility:** Windows 10 / Linux

### Database Architecture:
- Key entities: `Books`, `Users`, `Feedback`, `Orders/Bookings`
- Relational mapping with DFD Level 0, 1, 2 and ER diagram design.
